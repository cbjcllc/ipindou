# 参考站点分析记录

检查日期：2026-10-10。来源：用户给出的公开页面 https://webfem.com/tools/pindou/ 。

页面内可见工作流：JPG/PNG 上传；设置横向格数与色板；合并相似颜色、可选边缘背景移除、逐格编辑；显示逐色用量；导出带色号/网格/坐标/统计的 PNG 与 CSV。站点宣称图片在当前浏览器处理。

基于浏览器只读查看和其公开页面当前加载的前端 bundle 做功能观察。当前服务的公开 JavaScript 映射含 291 个 RGB 色值，每项映射至 MARD、COCO、漫漫、盼盼、咪小窝色号。网页算法采用 RGB 欧氏距离；初始网格单元可选 RGB 主色（跳过 alpha <128 的像素）或 RGB 平均色；之后对映射色作全局近邻颜色合并，并用边缘泛洪筛出连通背景。此仓库的转换代码为独立实现，映射表单独保存；没有复制站点脚本或 UI 代码。

https://cdn.webfem.com/static/pindous/_next/static/chunks/401-44a0b2482a8f53b0.js

具体数据与算法版本可能随来源站点更新。品牌色号按该公开映射表呈现，实际实物色差需参考购买的实体色卡。

实现范围与差异：此版本实现图片转换、五品牌色号显示、全局相似色合并、颜色数量限制、可选抖动、简化的边缘背景泛洪、单格编辑/擦除/撤销、PNG 与 CSV 导出。不是全站逐项克隆，也不宣称输出与原站逐像素一致。未实现 CSV 导入、原站作品历史/社区/成品图纸识别。超过 2048 像素的输入会先缩放；图纸两边均限制为 300 格。自动去背景使用图纸边缘主色，不等同于原站根据原始图片边缘进行的检测。

验证：在本地网页实际导入合成测试图，生成 48×48、2304 颗、3 色；切换 MARD/COCO 色号、擦除后减为 2303 颗、撤销恢复 2304 颗均通过。PNG/CSV Blob 下载链接生成成功，无页面控制台错误；内置浏览器未报告下载完成，因此磁盘落盘未验证。核心 Node 测试覆盖 291 条五品牌映射、主色/均色取样、透明像素、RGB 匹配、限色及连通边缘背景移除。
