# 豆点 · 图片转拼豆图纸

一个在浏览器本机完成图片转换的拼豆图纸工具。

## 启动

需要 Node.js 18 或更新版本。Windows 在此目录运行：

```powershell
node server.js
```

然后打开 http://localhost:8765 。停止服务按 Ctrl+C。也可设置 `PORT` 环境变量指定端口。

## 使用

1. 上传 PNG、JPG 或 WEBP 图片，或点击「导入 CSV 图纸」导入网格。CSV 单元格使用 `#RRGGBB`（也支持 `#RGB`），逗号之间留空表示空白格；导出的 CSV 也可直接再次导入。点击「裁剪照片」可拖动框选、移动选区、拖右下角缩放，也可输入像素坐标；取消保留原裁剪，恢复整张原图后应用可还原。
2. 选择 52×52、78×78、104×104 或自定义宽高（1～300 格）；也可按图片比例设置横向格数，并调整方向、取色方式、目标颜色数量与合并阈值。
默认方向为「填满画布」，合并相近颜色阈值为 30。「完整显示」会等比例留白；「填满画布」会按图纸比例居中裁切所选照片区域。

3. 可切换 MARD、COCO、漫漫、盼盼、咪小窝色号；开关颜色抖动与边缘背景移除。
4. 在用量清单中选择颜色，点击图纸格子改色；「色号管理」可搜索当前品牌全部 291 个色号、选作画笔、批量替换或移除图中色号，支持撤销。色号修改随图纸统计、PNG 和 CSV 导出更新；重新生成图纸会清除修改。
5. 导出有坐标、逐格色号与采购清单的 PNG，或含统计和逐格 HEX 网格的 CSV。

所有图片解码、转换、编辑、统计及导出均在浏览器中完成，不会由本地服务接收图片内容。文件大小限制 30 MB、像素数限制 4000 万，防止超大图片拖慢浏览器。

品牌色号映射和实现说明见 [docs/analysis.md](docs/analysis.md)。色号对应公开映射表，实体批次可能存在色差。
